## 🚀 Featured Projects

### 🍛 QR-Driven Restaurant Menu Display

A mobile-friendly digital menu for a restaurant:

- Customers scan a **static QR code** placed on tables  
- Opens a **GitHub Pages** site with a modern Tamil menu  
- Built with **HTML + Tailwind CSS + JavaScript**  
- Includes a **Share Menu** button with:
  - WhatsApp, Telegram, Email, Twitter/X, Facebook, Copy Link  
  - Uses `navigator.share()` on supported devices with fallback  

🔗 **Live Demo:**  
https://nikispace.github.io/QR-driven-menu-display/
